Input-handling simulator

Safe text previewYour input will appear here as text.

Learning point: untrusted input should be encoded for its output context. This demo displays your input as text rather than interpreting it as HTML.

Access-control decision

Signed-in demo user: customer-104. Requested order: order-205 (owned by customer-205).

Learning point: the server must verify ownership for every object request. Hiding a button is not authorization.

Use only systems you own or have explicit permission to test. The public NOVA demo is not a deliberately vulnerable server.
